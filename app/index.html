How this tracker works

Tick a trophy off and it stays ticked in this browser (localStorage). Counters track progress toward counted trophies — stunts, scans, vaults and the rest. Export saves your progress to a JSON file; Import brings it back on any device. Everything runs from these files alone: no network requests, no account, no tracking.

Cheats disable trophies and stop the game saving, so keep them off the file you use for this run.
